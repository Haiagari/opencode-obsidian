# Attributions
 
opencode-obsidian (Bunker OS) is an advanced knowledge architecture and persistent wiki operating system for OpenCode and Obsidian.
 
---
 
## Project Lineage & Core Architecture
 
- **LLM Wiki Pattern (Original Concept):** [Andrej Karpathy](https://github.com/karpathy) — Pioneered the core architecture of an LLM maintaining a compounding structured wiki from raw sources.
- **Base Fork (claude-obsidian):** [AgriciDaniel / AI Marketing Hub](https://github.com/AgriciDaniel/opencode-obsidian) — Created the original Claude Code vault implementation under the MIT License.
- **Bunker OS (Architecture & Maintenance):** Maintained and re-architected as **Bunker OS** by **Haiagari** — Multi-agent orchestration, resilient SQLite/FTS5 indexing, automated verification suites, n8n integrations, and OpenCode native tooling.

| Plugin | Author | Repository |
|--------|--------|-----------|
